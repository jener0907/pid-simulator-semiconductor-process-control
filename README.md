# PID Simulator for Semiconductor Process Control

A Streamlit simulator for comparing on-off, P, and PID controllers on an FOPDT temperature process.

## Run on Windows

Install Python, then double-click `run.bat`. See [설치 및 실행 가이드](설치_및_실행_가이드.md) for details.

## Deploy and share

1. Sign in to [Streamlit Community Cloud](https://share.streamlit.io/) with GitHub.
2. Select **Create app**, then choose this repository, the `main` branch, and `app.py`.
3. Deploy and share the resulting `*.streamlit.app` URL.

The app includes editable process/controller values, three graphs, a numerical data table, and CSV download. Commits pushed to GitHub are reflected in the deployed app.
